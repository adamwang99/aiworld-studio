# ADR 0001 — Name and initial scope

## Status
Accepted

## Decision
- Product name: **AI World Studio**
- Repo name: **`aiworld-studio`**
- Initial direction: unified operator-first app for transcript, subtitle, translation, voice, output packaging
- UI direction: VS-Brain-inspired **Glassmorphism dark / aurora / tím-cyan accents**

## Why
- Tên đủ rộng để mở rộng nhiều workflow
- Không khóa cứng vào 1 engine hay 1 tác vụ
- Hợp hướng nội bộ trước, sản phẩm hóa sau
- UI khác biệt, có nhận diện riêng, phù hợp operator console

## Consequences
- MVP cần giữ hẹp để tránh phình scope
- Engine layer phải modular
- Thiết kế phải ưu tiên runtime visibility hơn marketing visuals
